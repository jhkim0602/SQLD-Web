## 작성 순서 vs 실행 순서

| 단계 | 작성(논리) 순서 | 실행 순서 |
|---|---|---|
| 1 | SELECT | **FROM** |
| 2 | FROM | **WHERE** |
| 3 | WHERE | **GROUP BY** |
| 4 | GROUP BY | **HAVING** |
| 5 | HAVING | **SELECT** |
| 6 | ORDER BY | **ORDER BY** |

## 실행 순서가 만드는 규칙

### 1. WHERE에서는 집계함수 불가
```sql
-- ✗ 에러
SELECT deptno FROM emp WHERE COUNT(*) > 1;

-- ✓ HAVING 사용
SELECT deptno FROM emp GROUP BY deptno HAVING COUNT(*) > 1;
```
WHERE는 그룹핑 전에 실행되므로 집계 결과를 알 수 없다.

### 2. SELECT alias는 ORDER BY에서만 사용 가능
```sql
-- ✗ 에러 (WHERE는 SELECT 이전)
SELECT sal * 12 AS annual FROM emp WHERE annual > 10000;

-- ✓ ORDER BY는 SELECT 이후
SELECT sal * 12 AS annual FROM emp ORDER BY annual DESC;
```

### 3. ORDER BY는 SELECT에 없는 컬럼도 가능
SELECT에 명시되지 않은 컬럼도 ORDER BY에서 참조 가능. (단, DISTINCT와 함께 쓸 때는 제약 있음)

## 시각화

```
[디스크/메모리]
    ↓ FROM
[전체 행]
    ↓ WHERE (행 필터)
[조건 만족 행]
    ↓ GROUP BY (행 → 그룹)
[그룹]
    ↓ HAVING (그룹 필터)
[조건 만족 그룹]
    ↓ SELECT (컬럼 투영, alias 부여)
[결과]
    ↓ ORDER BY (정렬)
[최종]
```
