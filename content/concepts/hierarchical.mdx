## 1. 계층형 데이터란?

부모-자식 관계로 트리 구조를 이루는 데이터.

| 예시 | 부모 | 자식 |
|---|---|---|
| 조직 | 부서 → 팀 → 직원 |
| 게시판 | 게시글 → 답글 → 답답글 |
| 카테고리 | 대분류 → 중분류 → 소분류 |
| 자기참조 | 사원 → 부하 (mgr 컬럼) |

```
        KING (CEO)
       /    \
   JONES    BLAKE
   /  \      /  \
SCOTT FORD ALLEN WARD
```

## 2. CONNECT BY 구문 (Oracle) ⭐⭐⭐

```sql
SELECT LEVEL, empno, ename, mgr
FROM emp
START WITH mgr IS NULL          -- 루트 (시작점)
CONNECT BY PRIOR empno = mgr    -- 부모-자식 관계
ORDER SIBLINGS BY ename;        -- 형제 정렬
```

## 3. 핵심 키워드 ⭐⭐⭐

| 키워드 | 의미 |
|---|---|
| `START WITH` | 루트(시작) 조건 |
| `CONNECT BY` | 계층 관계 정의 |
| `PRIOR` | 부모 행의 컬럼 참조 |
| `LEVEL` | 계층 깊이 (루트=1) |
| `CONNECT_BY_ROOT` | 루트 행의 컬럼 값 |
| `CONNECT_BY_ISLEAF` | 리프 노드 여부 (1 또는 0) |
| `SYS_CONNECT_BY_PATH` | 루트부터 경로 문자열 |
| `ORDER SIBLINGS BY` | 형제 노드 정렬 |
| `NOCYCLE` | 순환 방지 |

> 🔑 **암기법: "스타-커넥-프-레-시블-패-오더"**
> START - CONNECT BY - PRIOR - LEVEL - SIBLINGS - PATH - ORDER SIBLINGS

## 4. PRIOR 위치 = 탐색 방향 ⭐⭐⭐ (시험 빈출)

> 💡 **핵심 규칙**: PRIOR가 붙은 쪽이 **부모**, 안 붙은 쪽이 **자식**

### Top-Down (위 → 아래)

\"부모.empno = 자식.mgr\" — 매니저에서 부하로

```sql
SELECT LEVEL, ename
FROM emp
START WITH mgr IS NULL
CONNECT BY PRIOR empno = mgr;   -- ← Top-Down
```

### Bottom-Up (아래 → 위)

\"자식.empno = 부모.mgr\" — 부하에서 매니저로 (역방향)

```sql
SELECT LEVEL, ename
FROM emp
START WITH ename = 'SCOTT'
CONNECT BY empno = PRIOR mgr;   -- ← Bottom-Up
```

> 🔑 **시험 단골**: \"PRIOR의 위치만 보면 Top-Down / Bottom-Up\"

## 5. LEVEL과 들여쓰기 표현

```sql
SELECT LPAD(' ', (LEVEL-1)*2) || ename AS hierarchy
FROM emp
START WITH mgr IS NULL
CONNECT BY PRIOR empno = mgr;
```

결과:
```
KING                 ← LEVEL 1
  JONES              ← LEVEL 2
    SCOTT            ← LEVEL 3
    FORD             ← LEVEL 3
  BLAKE              ← LEVEL 2
    ALLEN
    WARD
```

## 6. SYS_CONNECT_BY_PATH

루트부터 현재 노드까지의 경로 문자열.

```sql
SELECT ename,
       SYS_CONNECT_BY_PATH(ename, '/') AS path
FROM emp
START WITH mgr IS NULL
CONNECT BY PRIOR empno = mgr;
```

| ename | path |
|---|---|
| KING | /KING |
| JONES | /KING/JONES |
| SCOTT | /KING/JONES/SCOTT |

## 7. 리프 노드만 조회

```sql
SELECT ename
FROM emp
START WITH mgr IS NULL
CONNECT BY PRIOR empno = mgr;

-- 결과에 CONNECT_BY_ISLEAF = 1 필터
WHERE CONNECT_BY_ISLEAF = 1
```

## 8. 순환(Loop) 방지 — NOCYCLE

데이터 오류로 순환 발생 시 무한 루프 위험.

```sql
SELECT ename, LEVEL
FROM emp
START WITH mgr IS NULL
CONNECT BY NOCYCLE PRIOR empno = mgr;   -- ← 순환 차단

-- 순환 감지
SELECT ename, CONNECT_BY_ISCYCLE
FROM emp
START WITH mgr IS NULL
CONNECT BY NOCYCLE PRIOR empno = mgr;
```

## 9. 재귀 CTE (ANSI 표준) ⭐

다른 DBMS (PostgreSQL, SQL Server, MySQL 8+)에서 사용.

```sql
WITH RECURSIVE emp_tree (empno, ename, mgr, lvl) AS (
   -- 앵커 (시작점)
   SELECT empno, ename, mgr, 1
   FROM emp
   WHERE mgr IS NULL
   
   UNION ALL
   
   -- 재귀 (자식 추가)
   SELECT e.empno, e.ename, e.mgr, t.lvl + 1
   FROM emp e
   JOIN emp_tree t ON e.mgr = t.empno
)
SELECT * FROM emp_tree;
```

| | Oracle CONNECT BY | 재귀 CTE |
|---|---|---|
| 표준 | Oracle 전용 | ANSI 표준 |
| 가독성 | 간결 | 명시적 |
| 다른 DBMS | ✗ | ✓ |

## 10. ⚠️ 자주 틀리는 함정

1. **\"PRIOR 위치는 결과에 영향 없음\"** → ✗ Top-Down/Bottom-Up 결정
2. **\"LEVEL은 0부터 시작\"** → ✗ **1부터**
3. **\"CONNECT BY 없이 LEVEL 사용 가능\"** → ✗ 계층 질의에서만
4. **\"NOCYCLE은 순환 행을 제거\"** → ✗ 순환 진행을 막음 (행은 표시)
5. **\"START WITH 없으면 에러\"** → △ 생략 가능 (모든 행을 루트 후보로)
6. **\"SYS_CONNECT_BY_PATH는 자식부터\"** → ✗ **루트부터** 현재까지

## 11. 📝 기출 출제 패턴

### 패턴 A: PRIOR 방향 ⭐ 최빈출
> \"다음 쿼리는 Top-Down인가 Bottom-Up인가?\"
- PRIOR 위치 보기

### 패턴 B: LEVEL 의미
> \"LEVEL의 의미는?\"
- 계층 깊이 (루트=1)

### 패턴 C: SYS_CONNECT_BY_PATH
> \"루트부터 경로 표시 함수는?\"
- SYS_CONNECT_BY_PATH

### 패턴 D: 키워드 의미
- START WITH, CONNECT BY, PRIOR

## 12. 🔑 암기법 종합

| 항목 | 암기법 |
|---|---|
| 키워드 4종 | **스(START) 커(CONNECT) 프(PRIOR) 레(LEVEL)** |
| PRIOR 위치 | **\"PRIOR=부모\"** |
| Top-Down | **PRIOR empno = mgr** (부모.empno = 자식.mgr) |
| Bottom-Up | **empno = PRIOR mgr** (자식.empno = 부모.mgr) |
| LEVEL | **루트=1, 자식으로 갈수록 +1** |
| 경로 | **SYS_CONNECT_BY_PATH(col, sep)** |
| 리프 | **CONNECT_BY_ISLEAF = 1** |
| 순환 방지 | **NOCYCLE** |

## 13. 📌 시험 합격 핵심 요약

> **시험장 입실 5분 전 점검**

✅ **계층형 질의 4대 키워드**:
   - **START WITH**: 루트 조건
   - **CONNECT BY**: 계층 관계
   - **PRIOR**: 부모 참조
   - **LEVEL**: 깊이 (1부터)

✅ **PRIOR 위치 규칙**:
   - PRIOR가 붙은 쪽 = **부모**
   - 안 붙은 쪽 = **자식**

✅ **방향**:
   - `PRIOR empno = mgr` → **Top-Down** (부모→자식)
   - `empno = PRIOR mgr` → **Bottom-Up** (자식→부모)

✅ **유용한 함수**:
   - `SYS_CONNECT_BY_PATH(col, '/')`: 경로
   - `CONNECT_BY_ROOT col`: 루트 값
   - `CONNECT_BY_ISLEAF`: 리프 여부 (1/0)

✅ **빈출**: \"LEVEL은 루트가 1\"

✅ **빈출**: \"PRIOR 위치만 보면 방향 판단\"

✅ **다른 DBMS = 재귀 CTE** (WITH RECURSIVE)
