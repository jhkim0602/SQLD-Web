## 정의

**엔터티(Entity)**는 업무에서 관리해야 하는 의미 있는 정보의 집합이다. 일반적으로 명사(noun)로 표현되며, 한 개 이상의 인스턴스(instance)와 속성(attribute)을 가진다.

## 6가지 특징

1. **업무에서 필요한 정보**를 가져야 함
2. **유일한 식별자**로 식별 가능해야 함
3. **두 개 이상의 인스턴스의 집합**이어야 함
4. **영속적으로 존재**하는 인스턴스의 집합
5. **업무 프로세스에 의해 이용**되어야 함
6. **반드시 속성**을 가져야 함

> 단 하나의 인스턴스만 존재하는 것은 엔터티가 아닌 **상수**에 가깝다.

## 분류

| 기준 | 분류 |
|---|---|
| **유무형** | 유형(상품, 직원) / 개념(부서, 계정) / 사건(주문, 결재) |
| **발생 시점** | 기본/키엔터티 (독립적 발생, 예: 고객) / 중심엔터티 (기본+행위 결합, 예: 주문) / 행위엔터티 (행위 발생, 예: 주문상세) |

## 표기법

- **사각형**(또는 둥근 사각형): 엔터티
- 엔터티명: **단수 명사**, 업무에서 사용하는 용어, 약어 지양
