## 1. 정의

**엔터티(Entity)**는 업무 활동에서 관리해야 하는 의미 있는 정보를 가지는 사람·장소·사물·사건·개념의 집합이다. RDBMS에서는 **테이블**로 구현되며, 한 엔터티는 다수의 인스턴스를 포함한다.

> 💡 **엔터티 = 정보의 그릇**. 인스턴스는 그 안의 알맹이. 속성은 그릇의 모양을 결정하는 차원.

```
[학생 엔터티]
─────────────────────
학번 (PK)
이름
학과
입학년도
─────────────────────
인스턴스: (1001, 김철수, 컴공, 2024)
인스턴스: (1002, 이영희, 전자, 2024)
```

## 2. 엔터티의 6대 특징

| # | 특징 | 설명 |
|---|---|---|
| 1 | **업무에서 필요한 정보** | 업무 분석을 통해 도출됨 |
| 2 | **유일한 식별자** | PK로 인스턴스를 구분 |
| 3 | **영속적 존재** | 일회성이 아니라 지속 보존 |
| 4 | **2개 이상의 인스턴스 집합** | 단 하나면 상수에 가까움 |
| 5 | **업무 프로세스가 이용** | 어떤 프로세스도 사용 안 한다면 불필요 |
| 6 | **반드시 속성을 가짐** | 속성 없는 엔터티는 존재 X |

> 🔑 **암기법: "업유영2업속"**
> **업**무 정보 → **유**일 식별자 → **영**속적 → **2**개 이상 인스턴스 → **업**무 프로세스 → **속**성

## 3. 엔터티의 분류

### 3-1. 유무형에 따른 분류

| 분류 | 설명 | 예시 |
|---|---|---|
| **유형 엔터티** | 물리적 형태 존재 | 사원, 상품, 자동차 |
| **개념 엔터티** | 추상적·개념적 | 부서, 계정, 학과 |
| **사건 엔터티** | 행위·이벤트 | 주문, 결재, 강의수강 |

### 3-2. 발생 시점에 따른 분류 ⭐ 시험 빈출

| 분류 | 설명 | 예시 |
|---|---|---|
| **기본/키엔터티** | 독립적으로 발생, 다른 엔터티의 부모 | 사원, 부서, 고객, 상품 |
| **중심엔터티** | 기본엔터티로부터 발생, 업무의 중심 | 주문, 계약, 매출, 청구 |
| **행위엔터티** | 두 개 이상 엔터티 간 행위 결과 | 주문상세, 결재내역, 강의수강 |

> 🔑 **암기법: "기중행"** (기본 → 중심 → 행위)

## 4. 엔터티 명명 규칙

1. **현업에서 사용하는 용어** 사용 (개발자 임의어 X)
2. **단수 명사** (예: 고객 ○, 고객들 X)
3. **약어 지양** (이해도 우선)
4. **유일성** 보장 (같은 이름 둘 X)
5. **고유한 의미**의 단어 사용

## 5. ERD 표기법

```
┌─────────────┐
│   엔터티명   │  ← 사각형 (또는 둥근 사각형)
├─────────────┤
│ # PK 속성    │  ← 식별자 표시
│   일반 속성   │
│ * NOT NULL  │
└─────────────┘
```

- **IE 표기법**: 까마귀발(M), 동그라미(O=선택), 일자(|=1)
- **Barker 표기법**: 점선(선택), 실선(필수)

## 6. ⚠️ 자주 틀리는 함정

> 📌 **시험에서 함정으로 나오는 패턴**

1. **\"엔터티는 반드시 모든 속성에 값이 있어야 한다\"** → ✗ 거짓. NULL 허용 속성 가능
2. **\"엔터티는 1개의 인스턴스만 가질 수 있다\"** → ✗ 거짓. 2개 이상 필요
3. **\"속성이 없어도 엔터티가 될 수 있다\"** → ✗ 거짓. 반드시 속성 보유
4. **\"개념 엔터티는 실제로 존재하지 않으니 엔터티가 아니다\"** → ✗ 거짓. 추상적이어도 엔터티
5. **\"행위 엔터티는 기본 엔터티의 일종이다\"** → ✗ 거짓. 별개 분류

## 7. 📝 기출 출제 패턴

### 패턴 A: 엔터티 특징 고르기
> \"다음 중 엔터티의 특징으로 옳지 않은 것은?\"
- 6대 특징 중 하나가 살짝 변형되어 함정으로 출제
- **모든 속성에 값**, **1개의 인스턴스**, **속성 없음** 등이 오답 유도

### 패턴 B: 분류 구분
> \"발생 시점에 따른 분류로 옳지 않은 것은?\"
- 기본/중심/행위 분류에 \"물리/논리\" 같은 다른 기준 섞어 함정

### 패턴 C: 명명 규칙
> \"엔터티 명명 규칙으로 적절하지 않은 것은?\"
- 복수형 사용, 약어 사용, 개발자 임의 작명 등이 오답

## 8. 📌 시험 합격 핵심 요약

> **시험장 입실 5분 전 점검**

✅ **6대 특징 = 업유영2업속** (업무, 유일, 영속, 2+, 업무프로세스, 속성)

✅ **3대 분류 (발생) = 기중행** (기본 → 중심 → 행위)

✅ **3대 분류 (유무형) = 유개사** (유형 → 개념 → 사건)

✅ **명명**: 현업 용어, 단수, 약어 X, 유일

✅ **함정 1순위**: \"모든 속성에 값\" → 거짓 (NULL 허용)

✅ 식별자 속성은 반드시 값 존재, **일반 속성은 NULL 가능**
