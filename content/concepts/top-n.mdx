## 1. Top-N 쿼리란?

정렬된 결과에서 **상위 N건만** 추출. \"매출 상위 5개 상품\", \"부서별 급여 상위 3명\" 등.

## 2. 4가지 방법 비교 ⭐⭐⭐

| 방법 | 사용 | 장점 | 단점 |
|---|---|---|---|
| **ROWNUM** | Oracle 전버전 | 호환성 | 정렬과 함정 |
| **FETCH FIRST** | Oracle 12c+, ANSI | 직관, 표준 | 구버전 ✗ |
| **윈도우 함수** | 모던 DBMS | **그룹별 Top-N** | 약간 복잡 |
| **LIMIT** | MySQL, PG | 매우 간단 | Oracle ✗ |

## 3. ROWNUM (Oracle) ⭐⭐

```sql
-- 상위 5명
SELECT * FROM (
  SELECT * FROM emp ORDER BY sal DESC
) WHERE ROWNUM <= 5;
```

> ⚠️ **ROWNUM 함정**: 정렬 **전**에 부여됨 → 인라인 뷰 필수

```sql
-- ✗ 임의 5건만 뽑고 정렬
SELECT * FROM emp WHERE ROWNUM <= 5 ORDER BY sal DESC;

-- ✓ 정렬 후 ROWNUM 매김
SELECT * FROM (SELECT * FROM emp ORDER BY sal DESC) WHERE ROWNUM <= 5;
```

### 페이지네이션 함정 ⭐

```sql
-- ✗ 빈 결과 (ROWNUM은 1부터)
WHERE ROWNUM BETWEEN 6 AND 10;

-- ✓ 두 번 감싸기
SELECT * FROM (
  SELECT inner_q.*, ROWNUM AS rn FROM (
    SELECT * FROM emp ORDER BY sal DESC
  ) inner_q WHERE ROWNUM <= 10
) WHERE rn >= 6;
```

> 🔑 **암기법**: \"ROWNUM은 정렬 후, 페이지는 두 번 감싸기\"

## 4. FETCH FIRST (ANSI, Oracle 12c+) ⭐⭐

```sql
-- 상위 5건
SELECT * FROM emp ORDER BY sal DESC
FETCH FIRST 5 ROWS ONLY;

-- 페이지네이션
SELECT * FROM emp ORDER BY sal DESC
OFFSET 5 ROWS FETCH NEXT 5 ROWS ONLY;

-- 동률 포함
SELECT * FROM emp ORDER BY sal DESC
FETCH FIRST 5 ROWS WITH TIES;
```

## 5. 윈도우 함수 — 그룹별 Top-N ⭐⭐⭐

```sql
-- 부서별 급여 상위 3명
SELECT * FROM (
  SELECT e.*,
    RANK() OVER (PARTITION BY deptno ORDER BY sal DESC) AS r
  FROM emp e
) WHERE r <= 3;
```

### 순위 함수 선택

| 상황 | 함수 |
|---|---|
| **동률 모두 포함** | RANK |
| **정확히 N건만** | ROW_NUMBER |
| **동률 후 연속 순위** | DENSE_RANK |

## 6. 다른 DBMS 문법

```sql
-- SQL Server
SELECT TOP 5 * FROM emp ORDER BY sal DESC;
SELECT TOP 5 WITH TIES * FROM emp ORDER BY sal DESC;

-- MySQL / PostgreSQL
SELECT * FROM emp ORDER BY sal DESC LIMIT 5;
SELECT * FROM emp ORDER BY sal DESC LIMIT 5 OFFSET 5;
```

## 7. ⚠️ 자주 틀리는 함정

1. **\"ROWNUM은 정렬 후 부여\"** → ✗ 정렬 전
2. **\"ROWNUM BETWEEN 6 AND 10 가능\"** → ✗ 1부터 매겨야
3. **\"FETCH FIRST는 모든 버전\"** → ✗ Oracle 12c+
4. **\"WITH TIES는 정확히 N건\"** → ✗ N+α 가능
5. **\"Oracle도 LIMIT 가능\"** → ✗

## 8. 📝 기출 출제 패턴

### 패턴 A: ROWNUM 함정 ⭐
> \"왜 결과가 의도와 다른가?\"
- 정렬 전 ROWNUM 부여 → 인라인 뷰 필요

### 패턴 B: 그룹별 Top-N
> \"부서별 상위 3명?\"
- 윈도우 + 인라인 뷰

### 패턴 C: WITH TIES
> \"동률 포함 상위 5건?\"

### 패턴 D: 페이지네이션
> \"6~10위만?\"

## 9. 📌 실전 치트시트

> **핵심 구문 + 함정 + 빈출 패턴**

✅ **4가지 방법**: ROWNUM · FETCH FIRST · 윈도우 · LIMIT

✅ **ROWNUM 핵심 함정**:
   - **정렬 전 부여** → 반드시 인라인 뷰
   - 페이지네이션 = **두 번 감싸기**

✅ **FETCH FIRST**:
   - `N ROWS ONLY` — 정확히 N건
   - `WITH TIES` — 동률 포함
   - `OFFSET m ROWS FETCH NEXT n` — 페이지

✅ **그룹별 Top-N**:
   ```sql
   SELECT * FROM (
     SELECT *, RANK() OVER (PARTITION BY G ORDER BY X DESC) r
     FROM t
   ) WHERE r <= N;
   ```

✅ **빈출**: \"ROWNUM은 정렬 전 부여\"
