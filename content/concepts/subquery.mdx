## 1. 정의

**서브쿼리(Subquery)**는 다른 SQL 문 안에 포함된 SELECT 문. 메인쿼리의 일부로 동작.

## 2. 서브쿼리의 3축 분류 ⭐⭐⭐

### 축 1: 위치별

| 위치 | 이름 | 제약 |
|---|---|---|
| **SELECT 절** | 스칼라 서브쿼리 (Scalar) | **단일 행, 단일 컬럼** |
| **FROM 절** | 인라인 뷰 (Inline View) | 자유 (다중 행/컬럼) |
| **WHERE 절** | 중첩 서브쿼리 (Nested) | 연산자에 따라 |
| **HAVING 절** | 중첩 서브쿼리 | 집계 결과 비교용 |

> 🔑 **암기법: "스인중"** (스칼라·인라인뷰·중첩)

### 축 2: 반환 행수별

| 반환 | 사용 가능 연산자 |
|---|---|
| **단일 행** (1행) | `=`, `<>`, `<`, `>`, `<=`, `>=` |
| **다중 행** (여러 행) | `IN`, `NOT IN`, `ANY`, `ALL`, `EXISTS`, `NOT EXISTS` |
| **다중 컬럼** | `(c1, c2) IN ((v1, v2), ...)` |

> 🔑 **암기법**: 단일행은 **=계열**, 다중행은 **IN·ANY·ALL·EXISTS**

### 축 3: 메인쿼리 참조 여부

| 종류 | 메인 컬럼 참조 | 실행 횟수 |
|---|---|---|
| **비상관 (Non-Correlated)** | ✗ | **1번** |
| **상관 (Correlated)** | ○ | **메인 행마다** |

> 🔑 **암기법**: \"상관 = 메인을 본다\"

## 3. 스칼라 서브쿼리 (SELECT 절) ⭐⭐

**단일 행, 단일 컬럼**만 반환. 위반 시 에러.

```sql
SELECT e.ename,
  (SELECT d.dname FROM dept d WHERE d.deptno = e.deptno) AS 부서명
FROM emp e;
```

> ⚠️ **2건 이상 반환 시**: `ORA-01427: single-row subquery returns more than one row`

## 4. 인라인 뷰 (FROM 절) ⭐

서브쿼리 결과를 임시 테이블처럼.

```sql
SELECT * FROM (
  SELECT deptno, AVG(sal) AS avg_sal
  FROM emp
  GROUP BY deptno
) d
WHERE d.avg_sal > 2000;
```

- alias 필수
- 인라인 뷰 안의 ORDER BY는 보통 무시됨
- Top-N, 페이지네이션, 사전 집계에 자주 사용

### CTE (WITH 절) — 표준 대안

```sql
WITH dept_avg AS (
  SELECT deptno, AVG(sal) AS avg_sal FROM emp GROUP BY deptno
)
SELECT * FROM dept_avg WHERE avg_sal > 2000;
```

장점:
- 가독성 ↑
- **재사용** 가능
- 재귀 CTE로 계층 표현 가능

## 5. 중첩 서브쿼리 (WHERE 절) ⭐⭐

### 단일 행 서브쿼리

```sql
-- 평균보다 많이 받는 사원
SELECT * FROM emp WHERE sal > (SELECT AVG(sal) FROM emp);

-- 최고 급여 사원
SELECT * FROM emp WHERE sal = (SELECT MAX(sal) FROM emp);
```

### 다중 행 서브쿼리

```sql
-- IN: 어느 하나와 일치
SELECT * FROM emp 
WHERE deptno IN (SELECT deptno FROM dept WHERE loc = 'SEOUL');

-- ANY/SOME: 어느 하나라도
SELECT * FROM emp 
WHERE sal > ANY (SELECT sal FROM emp WHERE deptno = 10);
-- 10번 부서의 최소 급여보다라도 높은 사원

-- ALL: 모두
SELECT * FROM emp 
WHERE sal > ALL (SELECT sal FROM emp WHERE deptno = 10);
-- 10번 부서의 최대 급여보다 높은 사원

-- EXISTS: 매칭 존재 여부
SELECT * FROM emp e WHERE EXISTS (
  SELECT 1 FROM dept d WHERE d.deptno = e.deptno AND d.loc = 'SEOUL'
);
```

### ANY vs ALL ⭐⭐

| 연산자 | 의미 | 동치 |
|---|---|---|
| `> ANY (...)` | 최소값보다 큼 | `> MIN(...)` |
| `< ANY (...)` | 최대값보다 작음 | `< MAX(...)` |
| `> ALL (...)` | 최대값보다 큼 | `> MAX(...)` |
| `< ALL (...)` | 최소값보다 작음 | `< MIN(...)` |
| `= ANY` | IN과 동일 | `IN` |
| `<> ALL` | NOT IN과 동일 | `NOT IN` |

> 🔑 **암기법**: **\">ANY = >MIN\", \">ALL = >MAX\"**

## 6. 상관 서브쿼리 (Correlated) ⭐⭐

메인 행마다 재실행. 외부 컬럼 참조.

```sql
-- 부서별 최대 급여 사원
SELECT * FROM emp e
WHERE sal = (
  SELECT MAX(sal) FROM emp 
  WHERE deptno = e.deptno   -- ← 외부 컬럼 참조
);

-- 부서 평균보다 많이 받는 사원
SELECT * FROM emp e
WHERE sal > (
  SELECT AVG(sal) FROM emp WHERE deptno = e.deptno
);
```

### EXISTS는 거의 항상 상관

```sql
-- 사원이 있는 부서만
SELECT * FROM dept d
WHERE EXISTS (SELECT 1 FROM emp e WHERE e.deptno = d.deptno);
```

## 7. EXISTS vs IN vs JOIN ⭐⭐

| | 가독성 | 성능 | NULL 안전 |
|---|---|---|---|
| **IN** | 직관적 | 작은 결과셋 좋음 | NULL 함정 |
| **EXISTS** | 약간 복잡 | **첫 매치 시 종료** | 안전 |
| **JOIN** | 다른 컬럼도 필요할 때 | 빠름 | 안전 |

### NOT IN 함정 → NOT EXISTS 권장 ⭐⭐⭐

```sql
-- ✗ NOT IN에 NULL 섞이면 항상 빈 결과
WHERE deptno NOT IN (SELECT deptno FROM dept);

-- ✓ NULL 안전
WHERE NOT EXISTS (
  SELECT 1 FROM dept d WHERE d.deptno = e.deptno
);
```

> 📌 **시험 1순위 함정**: \"NOT IN + NULL = 빈 결과\"

## 8. 다중 컬럼 서브쿼리

```sql
-- 부서별 최대 급여 사원 (다중 컬럼)
SELECT * FROM emp
WHERE (deptno, sal) IN (
  SELECT deptno, MAX(sal) FROM emp GROUP BY deptno
);
```

## 9. ⚠️ 자주 틀리는 함정 종합

1. **\"스칼라 서브쿼리는 다중 행 OK\"** → ✗ 단일 행만
2. **\"인라인 뷰의 ORDER BY는 보장됨\"** → ✗ 보통 무시
3. **\"NOT IN과 NOT EXISTS는 항상 같다\"** → ✗ NULL에서 다름
4. **\"EXISTS는 결과 컬럼이 중요\"** → ✗ SELECT 1, * 무엇이든 동일
5. **\"`= ANY`는 ALL과 같다\"** → ✗ `= ANY` = IN
6. **\"비상관 서브쿼리는 행마다 실행\"** → ✗ 1번만
7. **\"WHERE col > ALL (...)에서 빈 집합이면 FALSE\"** → ✗ TRUE (모두 만족)

## 10. 📝 기출 출제 패턴

### 패턴 A: 위치별 분류 ⭐
> \"FROM 절에서 사용되는 서브쿼리의 이름은?\"
- 인라인 뷰

### 패턴 B: 스칼라 서브쿼리 ⭐
> \"스칼라 서브쿼리의 제약은?\"
- 단일 행, 단일 컬럼

### 패턴 C: NOT IN 함정 ⭐ 최빈출
> \"왜 결과가 비어 있는가?\"
- NULL 포함

### 패턴 D: ANY/ALL 의미
> \"> ANY와 동일한 것은?\"
- > MIN

### 패턴 E: EXISTS 사용
- 매칭 존재 여부, NULL 안전

## 11. 📌 실전 치트시트

> **핵심 구문 + 함정 + 빈출 패턴**

✅ **3축 분류 = 위치·행수·상관**

✅ **위치별 = 스인중**:
   - SELECT → 스칼라 (단일 행)
   - FROM → 인라인 뷰
   - WHERE → 중첩

✅ **연산자**:
   - 단일 행 = `=`, `>`, `<`, `<>`...
   - 다중 행 = `IN`, `ANY`, `ALL`, `EXISTS`

✅ **ANY vs ALL**:
   - `> ANY` = `> MIN` (어느 하나라도)
   - `> ALL` = `> MAX` (모두보다)
   - `= ANY` = `IN`
   - `<> ALL` = `NOT IN`

✅ **NOT IN + NULL = 빈 결과** → **NOT EXISTS** 사용

✅ **상관 = 외부 컬럼 참조**, 메인 행마다 실행

✅ **EXISTS는 첫 매치 시 종료** → 성능 좋음

✅ **CTE (WITH)** = 인라인 뷰의 가독성 향상판

### 🔑 암기법 정리

| 항목 | 암기법 |
|---|---|
| 3축 분류 | **위치·행수·상관** |
| 위치별 | **스인중** (스칼라·인라인·중첩) |
| 행수별 연산자 | **단일 = 계열 / 다중 IN·ANY·ALL·EXISTS** |
| ANY/ALL | **\">ANY=MIN, >ALL=MAX\"** |
| NOT IN 함정 | **\"NULL 섞이면 빈 집합\"** |
| 상관 | **\"외부 컬럼 참조 = 메인마다 실행\"** |
