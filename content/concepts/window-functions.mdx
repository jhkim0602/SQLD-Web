## 1. 정의

**윈도우 함수(Window Function) = 분석 함수(Analytic Function)**.

행 그룹(윈도우)에 함수를 적용하지만 **결과 행 수는 줄이지 않는다**.

> 💡 GROUP BY와 다른 핵심: 원본 행이 그대로 보존 + 그룹 통계 추가

```sql
-- GROUP BY: 행 수 감소
SELECT deptno, AVG(sal) FROM emp GROUP BY deptno;
-- 결과 3행 (부서별 1행씩)

-- 윈도우 함수: 행 수 유지 + 부서 평균 추가
SELECT ename, sal, AVG(sal) OVER (PARTITION BY deptno) FROM emp;
-- 결과 14행 (사원 수만큼)
```

## 2. 기본 구조 ⭐⭐⭐

```sql
함수() OVER (
  [PARTITION BY 컬럼1, 컬럼2 ...]    -- 그룹 분할
  [ORDER BY 컬럼 [ASC|DESC]]          -- 윈도우 내 순서
  [ROWS|RANGE BETWEEN ... AND ...]    -- 윈도우 프레임
)
```

| 절 | 역할 | 생략 시 |
|---|---|---|
| `PARTITION BY` | 그룹 분할 | 전체를 1개 윈도우 |
| `ORDER BY` | 윈도우 내 순서 | (순위·LAG는 필수) |
| `ROWS/RANGE` | 윈도우 프레임 | 기본 프레임 적용 |

## 3. 순위 함수 ⭐⭐⭐ (최빈출)

### 4가지 순위 함수

| 함수 | 동순위 처리 | 예시 (sal: 100, 100, 200, 300) |
|---|---|---|
| `RANK()` | 동순위 후 **건너뜀** | **1, 1, 3, 4** |
| `DENSE_RANK()` | 동순위 후 **연속** | **1, 1, 2, 3** |
| `ROW_NUMBER()` | 동순위 없음 | **1, 2, 3, 4** |
| `NTILE(n)` | n개 그룹 균등 분할 | 1~4 (n=4) |

> 🔑 **암기법: "랭덴로엔"** (RANK·DENSE_RANK·ROW_NUMBER·NTILE)

> 🔑 **차이 암기**: 
> - **RANK** = 건너뜀 (1, 1, **3**, 4)
> - **DENSE_RANK** = 빽빽 = 연속 (1, 1, **2**, 3)
> - **ROW_NUMBER** = 무조건 1씩 (1, 2, 3, 4)

```sql
SELECT ename, sal,
  RANK()       OVER (ORDER BY sal DESC) AS r,
  DENSE_RANK() OVER (ORDER BY sal DESC) AS dr,
  ROW_NUMBER() OVER (ORDER BY sal DESC) AS rn,
  NTILE(4)     OVER (ORDER BY sal DESC) AS quartile
FROM emp;
```

### PARTITION BY와 함께 — 그룹별 순위

```sql
-- 부서별 급여 순위
SELECT ename, deptno, sal,
  RANK() OVER (PARTITION BY deptno ORDER BY sal DESC) AS dept_rank
FROM emp;
```

## 4. 행 순서 함수 (LAG/LEAD) ⭐⭐

| 함수 | 동작 |
|---|---|
| `LAG(col, n, default)` | n행 **이전** 값 |
| `LEAD(col, n, default)` | n행 **다음** 값 |
| `FIRST_VALUE(col)` | 윈도우 첫 행 |
| `LAST_VALUE(col)` | 윈도우 마지막 행 (프레임 주의) |
| `NTH_VALUE(col, n)` | n번째 행 |

> 🔑 **암기법**: \"LAG = lag(뒤처짐) = 이전\", \"LEAD = 앞장 = 다음\"

```sql
SELECT ename, hiredate, sal,
  LAG(sal, 1, 0) OVER (ORDER BY hiredate) AS prev_sal,
  LEAD(sal, 1, 0) OVER (ORDER BY hiredate) AS next_sal
FROM emp;
```

### LAST_VALUE 함정 ⭐

```sql
-- ✗ 기본 프레임이 CURRENT ROW까지라 항상 본인 값
LAST_VALUE(sal) OVER (ORDER BY sal)

-- ✓ 프레임 명시
LAST_VALUE(sal) OVER (
  ORDER BY sal
  ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
)
```

## 5. 집계 함수의 윈도우 사용

`SUM`, `AVG`, `COUNT`, `MIN`, `MAX` 모두 OVER로 사용 가능.

```sql
SELECT ename, deptno, sal,
  SUM(sal) OVER (PARTITION BY deptno) AS dept_total,
  AVG(sal) OVER (PARTITION BY deptno) AS dept_avg,
  COUNT(*) OVER (PARTITION BY deptno) AS dept_cnt,
  MAX(sal) OVER (PARTITION BY deptno) AS dept_max
FROM emp;
```

### 누적합 (Running Total)

```sql
SUM(sal) OVER (
  ORDER BY hiredate
  ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
) AS cum_sal
```

### 이동평균 (Moving Average)

```sql
AVG(sal) OVER (
  ORDER BY hiredate
  ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
) AS moving_avg_3
```

## 6. 비율 함수

| 함수 | 의미 |
|---|---|
| `PERCENT_RANK()` | 순위 백분율 (0~1) |
| `CUME_DIST()` | 누적 분포 (0~1) |
| `RATIO_TO_REPORT(col)` | 합계 대비 비율 |

```sql
SELECT ename, sal,
  PERCENT_RANK() OVER (ORDER BY sal) AS pct_rank,
  CUME_DIST()    OVER (ORDER BY sal) AS cume_dist,
  RATIO_TO_REPORT(sal) OVER () AS ratio
FROM emp;
```

## 7. 윈도우 프레임 ⭐

| 키워드 | 의미 |
|---|---|
| `UNBOUNDED PRECEDING` | 첫 행부터 |
| `n PRECEDING` | n행 이전부터 |
| `CURRENT ROW` | 현재 행 |
| `n FOLLOWING` | n행 이후까지 |
| `UNBOUNDED FOLLOWING` | 마지막 행까지 |

### ROWS vs RANGE

- **ROWS**: 행 단위 (정확한 N행)
- **RANGE**: 값 단위 (동순위 그룹 묶음)

```sql
-- ROWS: 정확히 앞 2행
SUM(sal) OVER (ORDER BY id ROWS BETWEEN 2 PRECEDING AND CURRENT ROW)

-- RANGE: 값 기준 (같은 ORDER BY 값은 한꺼번에)
SUM(sal) OVER (ORDER BY sal RANGE BETWEEN 100 PRECEDING AND CURRENT ROW)
```

## 8. 그룹별 Top-N ⭐

윈도우 함수의 가장 강력한 활용.

```sql
-- 부서별 급여 상위 3명
SELECT * FROM (
  SELECT e.*,
    RANK() OVER (PARTITION BY deptno ORDER BY sal DESC) AS r
  FROM emp e
) WHERE r <= 3;
```

### 어떤 순위 함수를 쓸까?

| 상황 | 함수 |
|---|---|
| **동률 모두 포함** | RANK |
| **정확히 N건만** | ROW_NUMBER |
| **동률 후 연속 순위** | DENSE_RANK |

## 9. ⚠️ 자주 틀리는 함정

1. **\"WHERE에서 윈도우 함수 사용 가능\"** → ✗
   ```sql
   -- ✗ 에러
   SELECT * FROM emp WHERE RANK() OVER (...) <= 3;
   -- ✓ 인라인 뷰로 감싸기
   SELECT * FROM (SELECT *, RANK() OVER (...) r FROM emp) WHERE r <= 3;
   ```

2. **\"RANK는 동순위 후 연속\"** → ✗ 건너뜀

3. **\"LAST_VALUE는 항상 마지막\"** → ✗ 기본 프레임 함정

4. **\"PARTITION BY 생략 시 에러\"** → ✗ 전체 1개 윈도우

5. **\"ROW_NUMBER에서 동순위 발생 가능\"** → ✗ 무조건 고유

6. **\"순위 함수는 ORDER BY 생략 가능\"** → ✗ ORDER BY 없으면 결정적이지 않음

## 10. SQL 실행 순서에서의 위치

```
FROM → WHERE → GROUP BY → HAVING → 윈도우 함수 → SELECT → ORDER BY
```

윈도우 함수는 **SELECT 단계**에서 평가. 그래서:
- WHERE/HAVING에서 사용 ✗
- ORDER BY에서 사용 ○
- 인라인 뷰로 감싸야 결과 필터 가능

## 11. 📝 기출 출제 패턴

### 패턴 A: 순위 함수 결과 ⭐ 최빈출
> \"RANK, DENSE_RANK, ROW_NUMBER 결과는?\"
- 1,1,**3**,4 / 1,1,**2**,3 / 1,2,3,4

### 패턴 B: LAG/LEAD
> \"LAG(sal, 1, 0)의 의미는?\"
- 이전 행 sal, 없으면 0

### 패턴 C: 프레임
> \"누적합 만드는 윈도우 프레임은?\"
- ROWS UNBOUNDED PRECEDING TO CURRENT ROW

### 패턴 D: WHERE에서 사용
> \"WHERE RANK() OVER (...) <= 3 가능?\"
- ✗ (인라인 뷰 필요)

## 12. 📌 실전 치트시트

> **핵심 구문 + 함정 + 빈출 패턴**

✅ **순위 함수 = 랭덴로엔**:
   - RANK: 동순위 후 **건너뜀** (1,1,**3**,4)
   - DENSE_RANK: 동순위 후 **연속** (1,1,**2**,3)
   - ROW_NUMBER: **무조건 +1** (1,2,3,4)
   - NTILE(n): n개 그룹

✅ **LAG/LEAD**:
   - `LAG(col, n, default)`: n행 이전
   - `LEAD(col, n, default)`: n행 다음

✅ **윈도우 프레임 = 누적합**:
   - `ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW`

✅ **ROWS vs RANGE**: 행 단위 vs 값 단위

✅ **WHERE에서 윈도우 함수 ✗** → 인라인 뷰

✅ **PARTITION BY 생략 = 전체 1개 윈도우**

✅ **빈출**: \"RANK 결과 1,1,?,4에서 ?\" → **3** (건너뜀)
