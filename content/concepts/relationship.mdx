## 정의

**관계(Relationship)**는 엔터티 간의 연관성을 의미한다. 두 엔터티 간 인스턴스 사이의 페어링(pairing)으로 나타난다.

## 3가지 구성 요소

| 요소 | 설명 | 예 |
|---|---|---|
| **관계명 (Relationship Name)** | 관계의 명칭 | 주문하다, 소속되다 |
| **관계차수 (Cardinality)** | 인스턴스 참여 수 | 1:1, 1:M, M:N |
| **관계선택성 (Optionality)** | 참여가 필수/선택 | NOT NULL FK / NULL 허용 FK |

## 관계 차수(Cardinality)

```
[고객] —— 1:M —— [주문]
```
한 고객은 여러 주문을 가질 수 있고, 한 주문은 한 고객에게 속한다.

- **1:1**: 직원 ↔ 사원증
- **1:M**: 고객 ↔ 주문
- **M:N**: 학생 ↔ 과목 (교차 엔터티로 풀어내야 함)

## 관계 선택성(Optionality)

- **필수참여**: 인스턴스가 반드시 관계에 참여 → FK NOT NULL
- **선택참여**: 참여하지 않을 수 있음 → FK NULL 허용

## 식별/비식별 관계

| 종류 | 설명 |
|---|---|
| **식별 관계 (Identifying)** | 부모의 PK가 자식의 PK + FK가 됨. 자식이 부모에 종속. |
| **비식별 관계 (Non-Identifying)** | 부모의 PK가 자식의 일반 속성(FK)으로만 들어감. |

ERD에서 실선은 식별 관계, 점선은 비식별 관계를 의미한다.
