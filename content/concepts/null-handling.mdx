## NULL은 "값이 없음"

NULL은 **알 수 없음(Unknown)** 또는 **값이 정의되지 않음**을 의미. **0이나 빈 문자열과 다름**.

> ⚠️ **Oracle 특수**: Oracle은 빈 문자열 `''`을 NULL로 취급. 다른 DBMS는 다를 수 있다.

```sql
-- Oracle
SELECT * FROM emp WHERE comment = '';   -- 절대 매칭 안 됨 (NULL = NULL 함정)
SELECT * FROM emp WHERE comment IS NULL;
```

## 비교 연산 규칙

| 표현식 | 결과 | 비고 |
|---|---|---|
| `NULL = NULL` | UNKNOWN | TRUE 아님 |
| `NULL <> NULL` | UNKNOWN | FALSE 아님 |
| `NULL = 1` | UNKNOWN | |
| `1 + NULL` | NULL | 사칙연산은 NULL |
| `'A' \|\| NULL` | 'A' (Oracle) | 일부 DBMS는 NULL |
| `NULL IS NULL` | **TRUE** ✓ | NULL 판별 |
| `NULL IS NOT NULL` | **FALSE** | |

> 📌 **핵심 규칙**: NULL과의 비교는 반드시 `IS NULL` / `IS NOT NULL`.

## 3치 논리 (Three-Valued Logic)

SQL은 TRUE/FALSE/UNKNOWN의 3치 논리를 사용.

### AND 진리표

| | T | F | U |
|---|---|---|---|
| **T** | T | F | U |
| **F** | F | F | F |
| **U** | U | F | U |

### OR 진리표

| | T | F | U |
|---|---|---|---|
| **T** | T | T | T |
| **F** | T | F | U |
| **U** | T | U | U |

### NOT

- NOT T = F
- NOT F = T
- **NOT U = U** ← 함정

`WHERE` 절은 **TRUE인 행만** 통과시킨다. UNKNOWN/FALSE는 제외.

## 집계함수와 NULL

> ⚠️ **시험 1순위 함정**

| 함수 | NULL 처리 |
|---|---|
| `COUNT(*)` | NULL 포함, **전체 행** 수 |
| `COUNT(컬럼)` | NULL **제외** |
| `COUNT(DISTINCT 컬럼)` | NULL 제외 + 중복 제거 |
| `SUM(컬럼)` | NULL 무시하고 합산 |
| `AVG(컬럼)` | NULL 무시 (**분자, 분모 모두**) |
| `MIN/MAX(컬럼)` | NULL 무시 |
| `STDDEV/VARIANCE` | NULL 무시 |

### 자주 틀리는 예

```
emp.sal: 100, NULL, 200, 300

COUNT(*)        = 4
COUNT(sal)      = 3              ← NULL 1건 제외
SUM(sal)        = 600
AVG(sal)        = 600 / 3 = 200  ← 600/4 아님!
MIN(sal)        = 100
MAX(sal)        = 300
```

### COUNT의 함정

```sql
-- 부서별 인원수 (NULL 포함)
SELECT deptno, COUNT(*) FROM emp GROUP BY deptno;

-- 부서별 매니저 있는 인원수 (NULL 제외)
SELECT deptno, COUNT(mgr) FROM emp GROUP BY deptno;
```

## DISTINCT, GROUP BY, ORDER BY에서의 NULL

NULL을 **하나의 값으로 묶어** 처리.

```sql
-- emp.deptno: 10, 10, 20, NULL, NULL, 30
SELECT DISTINCT deptno FROM emp;
-- 결과: 10, 20, 30, NULL  (4건, NULL이 하나로 묶임)

SELECT deptno, COUNT(*) FROM emp GROUP BY deptno;
-- NULL 그룹도 별도로 카운트됨
```

비교 시: UNKNOWN, 묶을 때: 동일. 헷갈리지 말 것.

### 정렬에서의 NULL

- **Oracle**: ASC면 NULL이 **마지막**, DESC면 **처음**
- **SQL Server, MySQL**: ASC면 NULL이 **처음**

명시적 제어:
```sql
ORDER BY sal DESC NULLS LAST;
ORDER BY sal ASC NULLS FIRST;
```

## IN, NOT IN의 NULL 함정

```sql
-- ✓ 의도대로 동작
WHERE deptno IN (10, 20, NULL)
-- = deptno=10 OR deptno=20 OR deptno=NULL
-- = TRUE OR TRUE OR UNKNOWN
-- → TRUE인 행만 (NULL 행은 제외, 일반 10/20 행은 통과)

-- ✗ 결과가 항상 비어버림!
WHERE deptno NOT IN (10, 20, NULL)
-- = deptno<>10 AND deptno<>20 AND deptno<>NULL
-- = ... AND UNKNOWN
-- → UNKNOWN ⇒ WHERE 통과 X
```

> 📌 **시험 최빈출 함정**: `NOT IN`에 NULL이 섞이면 **항상 빈 결과**.

해결책:
```sql
-- 방법 1: NULL 제거
WHERE deptno NOT IN (SELECT deptno FROM dept WHERE deptno IS NOT NULL)

-- 방법 2: NOT EXISTS (NULL 안전)
WHERE NOT EXISTS (
  SELECT 1 FROM dept d WHERE d.deptno = e.deptno
)
```

## NULL 변환 함수

| 함수 | 동작 | 표준 |
|---|---|---|
| `NVL(a, b)` | a가 NULL이면 b | Oracle |
| `NVL2(a, b, c)` | a NOT NULL이면 b, NULL이면 c | Oracle |
| `COALESCE(a, b, c, ...)` | 처음 non-NULL 반환 | **ANSI 표준** |
| `NULLIF(a, b)` | a==b이면 NULL, 아니면 a | 표준 |
| `ISNULL(a, b)` | a가 NULL이면 b | SQL Server |
| `IFNULL(a, b)` | a가 NULL이면 b | MySQL |

### COALESCE 활용 예

```sql
-- 우선순위 적용
SELECT COALESCE(office_phone, mobile_phone, '연락처 없음')
FROM emp;
```

## JOIN에서의 NULL

```sql
-- emp.deptno: 10, NULL, 20
-- dept.deptno: 10, 20, 30

-- INNER JOIN
SELECT * FROM emp e JOIN dept d ON e.deptno = d.deptno;
-- 결과: 2행 (NULL인 emp 행은 매칭 안 됨)

-- LEFT OUTER JOIN
SELECT * FROM emp e LEFT JOIN dept d ON e.deptno = d.deptno;
-- 결과: 3행 (NULL인 emp 행도 포함, d 컬럼은 NULL)
```

## 외래키와 NULL

```sql
-- FK는 NULL 허용 가능 (선택 참여)
CREATE TABLE emp (
  empno NUMBER PRIMARY KEY,        -- NULL 불가
  deptno NUMBER,                   -- NULL 가능 (부서 미배정)
  CONSTRAINT fk FOREIGN KEY (deptno) REFERENCES dept (deptno)
);
```

| 키 | NULL |
|---|---|
| PRIMARY KEY | 불가 (개체 무결성) |
| UNIQUE | 가능 (여러 NULL 공존 가능) |
| FOREIGN KEY | 가능 (선택 참여) |

## 시험 빈출 체크리스트

> 📌 **꼭 외울 것**
>
> 1. NULL과의 `=` 비교는 항상 UNKNOWN → `IS NULL` 사용
> 2. `COUNT(*)`만 NULL 포함, `COUNT(컬럼)`은 제외
> 3. `AVG`의 분모는 NULL이 아닌 행 수
> 4. `NOT IN (..., NULL)`은 항상 빈 결과 → `NOT EXISTS` 사용
> 5. `DISTINCT`, `GROUP BY`에서는 NULL을 하나로 묶음
> 6. Oracle 정렬: ASC면 NULL 마지막
> 7. FK는 NULL 허용, PK는 불허
> 8. 빈 문자열 `''`은 Oracle에서 NULL로 취급
> 9. `+ NULL`은 NULL (사칙연산)
> 10. `\|\| NULL`은 그냥 무시 (Oracle 문자열 결합)
