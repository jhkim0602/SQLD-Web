## 1. NULL은 무엇인가?

**NULL = \"값이 없음\"** 또는 **\"알 수 없음(Unknown)\"**.

> ⚠️ **NULL은 0이 아니다. 빈 문자열도 아니다.**

| | NULL | 0 | '' |
|---|---|---|---|
| 의미 | 알 수 없음 | 숫자 0 | 빈 문자열 |
| 비교 | UNKNOWN | 비교 가능 | 비교 가능 |
| 연산 | NULL 전파 | 정상 | 정상 |

> 🚨 **Oracle 특수**: 빈 문자열 `''`을 **NULL로 취급**한다. 다른 DBMS와 다름.

## 2. 비교 연산 규칙 ⭐⭐⭐

| 표현식 | 결과 |
|---|---|
| `NULL = NULL` | **UNKNOWN** (TRUE 아님) |
| `NULL <> NULL` | UNKNOWN |
| `NULL = 1` | UNKNOWN |
| `NULL > 1` | UNKNOWN |
| `1 + NULL` | **NULL** (사칙연산은 NULL 전파) |
| `'A' \|\| NULL` | 'A' (Oracle), NULL (일부) |
| `NULL IS NULL` | **TRUE** ✓ |
| `NULL IS NOT NULL` | FALSE |

> 🔑 **핵심 규칙**: NULL과의 비교는 반드시 **`IS NULL` / `IS NOT NULL`**

## 3. 3치 논리 (Three-Valued Logic) ⭐⭐

SQL은 TRUE / FALSE / **UNKNOWN**의 3치 논리.

### AND 진리표

|       | T | F | U |
|-------|---|---|---|
| **T** | T | F | U |
| **F** | F | F | F |
| **U** | U | F | U |

### OR 진리표

|       | T | F | U |
|-------|---|---|---|
| **T** | T | T | T |
| **F** | T | F | U |
| **U** | T | U | U |

### NOT 진리표

| 입력 | NOT |
|---|---|
| T | F |
| F | T |
| **U** | **U** ← 함정! |

> ⚠️ **WHERE 절은 TRUE인 행만 통과**. UNKNOWN/FALSE는 제외.

## 4. 집계함수와 NULL ⭐⭐⭐ (시험 1순위)

| 함수 | NULL 처리 |
|---|---|
| `COUNT(*)` | NULL **포함**, 전체 행 수 |
| `COUNT(컬럼)` | NULL **제외** |
| `COUNT(DISTINCT 컬럼)` | NULL 제외 + 중복 제거 |
| `SUM(컬럼)` | NULL 무시하고 합산 |
| `AVG(컬럼)` | NULL 무시 (**분자, 분모 모두**) |
| `MIN/MAX(컬럼)` | NULL 무시 |
| `STDDEV/VARIANCE` | NULL 무시 |

### 자주 틀리는 예 (가장 빈출)

```
emp.sal: 100, NULL, 200, 300  (4건)

COUNT(*)        = 4
COUNT(sal)      = 3              ← NULL 1건 제외
SUM(sal)        = 600
AVG(sal)        = 600 / 3 = 200  ← 600/4 = 150 아님!
MIN(sal)        = 100
MAX(sal)        = 300
```

> 🔑 **핵심**: `AVG`의 분모는 **NULL이 아닌 행의 수**.

## 5. DISTINCT, GROUP BY, ORDER BY의 NULL ⭐

비교에서는 UNKNOWN, **묶을 때는 하나의 값**으로 처리.

```sql
-- emp.deptno: 10, 10, 20, NULL, NULL, 30
SELECT DISTINCT deptno FROM emp;
-- 결과: 10, 20, 30, NULL (4건)

SELECT deptno, COUNT(*) FROM emp GROUP BY deptno;
-- NULL 그룹도 별도로 카운트
```

### 정렬에서의 NULL

| DBMS | ASC | DESC |
|---|---|---|
| **Oracle** | NULL **마지막** | NULL **처음** |
| SQL Server, MySQL | NULL 처음 | NULL 마지막 |

명시적 제어:
```sql
ORDER BY sal DESC NULLS LAST;
ORDER BY sal ASC NULLS FIRST;
```

## 6. IN, NOT IN의 NULL 함정 ⭐⭐⭐ (시험 최빈출)

```sql
-- ✓ 의도대로 동작
WHERE deptno IN (10, 20, NULL)
-- = deptno=10 OR deptno=20 OR deptno=NULL
-- = TRUE OR TRUE OR UNKNOWN
-- → TRUE인 행이 통과

-- ✗ 결과가 항상 비어버림!
WHERE deptno NOT IN (10, 20, NULL)
-- = deptno<>10 AND deptno<>20 AND deptno<>NULL
-- = ... AND UNKNOWN
-- → UNKNOWN ⇒ WHERE 통과 X
```

> 🚨 **시험 단골 함정**: **`NOT IN`에 NULL이 섞이면 항상 빈 결과**

### 해결책

```sql
-- 방법 1: NULL 제거
WHERE deptno NOT IN (
  SELECT deptno FROM dept WHERE deptno IS NOT NULL
);

-- 방법 2: NOT EXISTS (NULL 안전)
WHERE NOT EXISTS (
  SELECT 1 FROM dept d WHERE d.deptno = e.deptno
);
```

## 7. NULL 변환 함수 ⭐⭐

| 함수 | 동작 | 표준 |
|---|---|---|
| `NVL(a, b)` | a가 NULL이면 b | Oracle |
| `NVL2(a, b, c)` | a NOT NULL이면 b, NULL이면 c | Oracle |
| `COALESCE(a, b, c, ...)` | 처음 non-NULL | **ANSI 표준** |
| `NULLIF(a, b)` | a==b이면 NULL, 아니면 a | 표준 |
| `ISNULL(a, b)` | a가 NULL이면 b | SQL Server |
| `IFNULL(a, b)` | a가 NULL이면 b | MySQL |

```sql
SELECT
  NVL(NULL, 'A'),                       -- 'A'
  NVL2(NULL, 'B', 'A'),                 -- 'A'
  NVL2('X', 'B', 'A'),                  -- 'B'
  COALESCE(NULL, NULL, 'X', 'Y'),       -- 'X'
  NULLIF('A', 'A'),                     -- NULL
  NULLIF('A', 'B')                      -- 'A'
FROM dual;
```

> 🔑 **암기법**: 
> - **NVL**: \"Null이면 Value로\"
> - **COALESCE**: \"합쳐 (Co-) 처음 의미 있는 것\"
> - **NULLIF**: \"같으면 NULL을\"

## 8. JOIN에서의 NULL

```
emp.deptno: 10, NULL, 20
dept.deptno: 10, 20, 30
```

| JOIN | 결과 |
|---|---|
| INNER | 2행 (NULL emp는 매칭 안 됨) |
| LEFT OUTER | 3행 (NULL emp 포함, dept는 NULL) |
| FULL OUTER | 4행 (양쪽 모두) |

## 9. 외래키와 NULL

| 키 | NULL 허용 |
|---|---|
| PRIMARY KEY | ✗ (개체 무결성) |
| UNIQUE | **○** (여러 NULL 공존 OK) |
| FOREIGN KEY | **○** (선택 참여) |
| NOT NULL | ✗ |

## 10. ⚠️ 자주 틀리는 함정 종합

1. **\"NULL = NULL은 TRUE\"** → ✗ UNKNOWN
2. **\"COUNT(*)는 NULL 제외\"** → ✗ 포함
3. **\"AVG의 분모는 전체 행 수\"** → ✗ NULL 아닌 행 수
4. **\"NOT IN은 항상 IN의 반대\"** → ✗ NULL 함정
5. **\"DISTINCT는 NULL 제거\"** → ✗ NULL도 한 그룹
6. **\"ORDER BY ASC에서 NULL은 항상 처음\"** → △ Oracle은 마지막
7. **\"FK는 NULL 불가\"** → ✗ 허용
8. **\"빈 문자열 ''은 NULL이 아니다\"** → △ Oracle은 NULL
9. **\"1 + NULL = 1\"** → ✗ NULL
10. **\"WHERE col = NULL\"** → ✗ 항상 거짓 (IS NULL 사용)

## 11. 📝 기출 출제 패턴

### 패턴 A: 집계함수 NULL 처리 ⭐ 최빈출
> \"다음 쿼리의 결과는? (NULL이 섞인 데이터)\"
- COUNT(*), COUNT(col), AVG의 분모 함정

### 패턴 B: NOT IN 함정 ⭐
> \"왜 결과가 비어 있는가?\"
- 서브쿼리에 NULL 포함

### 패턴 C: 비교 연산
> \"WHERE deptno = NULL의 결과는?\"
- UNKNOWN → 빈 결과

### 패턴 D: NULL 변환 함수
> \"NVL, NVL2, NULLIF의 차이는?\"
- 인자 수와 동작

## 12. 📌 함수 매트릭스 한눈

> **함수 비교 · 결과 차이 · NULL 함정**

✅ **NULL과의 비교는 UNKNOWN**, `IS NULL` 사용

✅ **AVG의 분모는 NULL 아닌 행 수**
   - (100, NULL, 200, 300) → AVG = 600/3 = **200**

✅ **COUNT(*)만 NULL 포함**, COUNT(컬럼)은 제외

✅ **NOT IN + NULL = 항상 공집합** → **NOT EXISTS** 사용

✅ **DISTINCT/GROUP BY는 NULL을 한 그룹으로**

✅ **NULL 변환**: NVL(2개) · NVL2(3개) · COALESCE(다중) · NULLIF(같으면 NULL)

✅ **NULL 허용**:
   - PK ✗ | UNIQUE ○ | FK ○ | NOT NULL ✗

✅ **Oracle 특수**: 빈 문자열 `''` = NULL

✅ **사칙연산**: NULL 전파 (1+NULL = NULL)

### 🔑 암기법 정리

| 항목 | 암기법 |
|---|---|
| 비교 시 | **\"NULL은 IS NULL로\"** |
| AVG 분모 | **\"NULL 빼고 나누기\"** |
| NOT IN 함정 | **\"NOT IN + NULL = 항상 공집합\"** |
| FK NULL | **\"FK는 NULL OK, PK는 NULL NO\"** |
| 사칙연산 | **\"NULL 전파\" (1+NULL = NULL)** |
