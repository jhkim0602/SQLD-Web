## NULL은 "값이 없음"

NULL은 **0이나 빈 문자열과 다르다**. "알 수 없음(Unknown)" 또는 "값이 정의되지 않음"을 의미한다.

## 비교 연산 규칙

| 표현식 | 결과 |
|---|---|
| `NULL = NULL` | UNKNOWN |
| `NULL <> 1` | UNKNOWN |
| `1 + NULL` | NULL |
| `NULL IS NULL` | TRUE ✓ |
| `NULL IS NOT NULL` | FALSE |

> **NULL과의 비교는 반드시 `IS NULL` / `IS NOT NULL`을 사용**해야 한다. `=`나 `<>`는 항상 UNKNOWN.

## 집계함수와 NULL

| 함수 | NULL 처리 |
|---|---|
| `COUNT(*)` | NULL **포함**, 전체 행 |
| `COUNT(컬럼)` | NULL **제외** |
| `SUM(컬럼)` | NULL 무시 |
| `AVG(컬럼)` | NULL 무시 (분자, **분모 모두**) |
| `MIN/MAX(컬럼)` | NULL 무시 |

### 자주 틀리는 함정

```
sal: 100, NULL, 200, 300
COUNT(*)      = 4
COUNT(sal)    = 3
SUM(sal)      = 600
AVG(sal)      = 600 / 3 = 200   ← 600/4 아님!
```

## NULL 변환 함수

| 함수 | 동작 |
|---|---|
| `NVL(a, b)` | a가 NULL이면 b 반환 (Oracle) |
| `ISNULL(a, b)` | 동일 (SQL Server) |
| `COALESCE(a, b, c, ...)` | 처음으로 NULL이 아닌 값 반환 (표준) |
| `NULLIF(a, b)` | a == b이면 NULL, 아니면 a |

## 정렬에서의 NULL

- **Oracle**: 오름차순 시 NULL은 **마지막**, 내림차순 시 **처음**. `NULLS FIRST` / `NULLS LAST`로 명시 가능.
- 다른 DBMS는 반대일 수 있음.
