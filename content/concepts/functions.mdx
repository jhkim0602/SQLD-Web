## 함수 분류

| 분류 | 예시 |
|---|---|
| **단일 행 함수** (Single-Row) | UPPER, SUBSTR, ROUND, TO_CHAR |
| **다중 행 함수** (Multi-Row, 집계) | SUM, AVG, COUNT, MAX, MIN |
| **분석 함수** (Analytic, 윈도우) | RANK, LAG, ROW_NUMBER |

## 문자 함수

| 함수 | 동작 | 예 |
|---|---|---|
| `LENGTH(s)` | 문자 수 | `LENGTH('SQL') = 3` |
| `LENGTHB(s)` | 바이트 수 | 한글 1자 = 3바이트 (UTF-8) |
| `UPPER/LOWER(s)` | 대소문자 변환 | `UPPER('sql') = 'SQL'` |
| `INITCAP(s)` | 첫 글자만 대문자 | `INITCAP('hello world') = 'Hello World'` |
| `SUBSTR(s, start, len)` | 부분 추출 (1-based) | `SUBSTR('SQLD', 2, 2) = 'QL'` |
| `INSTR(s, sub)` | 위치 검색 | `INSTR('SQLD', 'D') = 4` |
| `REPLACE(s, old, new)` | 치환 | `REPLACE('AAA', 'A', 'B') = 'BBB'` |
| `LPAD(s, n, c)` | 좌측 패딩 (전체 길이 n) | `LPAD('1', 3, '0') = '001'` |
| `RPAD(s, n, c)` | 우측 패딩 | `RPAD('1', 3, '0') = '100'` |
| `TRIM(s)` | 공백 제거 (양쪽) | `TRIM('  AB  ') = 'AB'` |
| `LTRIM/RTRIM` | 좌/우 제거 | |
| `CONCAT(a, b)` 또는 `\|\|` | 결합 | `'A' \|\| 'B' = 'AB'` |

> ⚠️ **함정**: `SUBSTR(s, start, len)`에서 start는 **1부터** 시작 (Oracle). `SUBSTR('SQLD', 0, 2)`는 'SQ' (0과 1을 같게 취급).

## 숫자 함수

| 함수 | 동작 | 예 |
|---|---|---|
| `ROUND(n, d)` | 반올림 | `ROUND(3.456, 1) = 3.5` |
| `TRUNC(n, d)` | 절사 (버림) | `TRUNC(3.999, 0) = 3` |
| `CEIL(n)` | 올림 (큰 값 방향) | `CEIL(-3.2) = -3`, `CEIL(3.2) = 4` |
| `FLOOR(n)` | 내림 (작은 값 방향) | `FLOOR(-3.2) = -4`, `FLOOR(3.2) = 3` |
| `MOD(a, b)` | 나머지 | `MOD(10, 3) = 1` |
| `ABS(n)` | 절대값 | `ABS(-5) = 5` |
| `SIGN(n)` | 부호 (-1, 0, 1) | `SIGN(-3) = -1` |
| `POWER(n, m)` | 거듭제곱 | `POWER(2, 10) = 1024` |
| `SQRT(n)` | 제곱근 | `SQRT(16) = 4` |

> 💡 **CEIL vs FLOOR 음수 함정**: CEIL은 더 큰 값(0 방향), FLOOR는 더 작은 값(-∞ 방향).

## 날짜 함수

| 함수 | 동작 |
|---|---|
| `SYSDATE` | 현재 일시 (DB 서버) |
| `CURRENT_DATE` | 현재 날짜 (세션 시간대) |
| `SYSTIMESTAMP` | 현재 타임스탬프 |
| `ADD_MONTHS(d, n)` | n개월 후 |
| `MONTHS_BETWEEN(d1, d2)` | 월 차이 (소수 포함) |
| `NEXT_DAY(d, '월요일')` | 다음 특정 요일 |
| `LAST_DAY(d)` | 해당 월의 마지막 날 |
| `TRUNC(d, 'MM')` | 해당 월의 1일 |
| `EXTRACT(YEAR FROM d)` | 연도 추출 |

```sql
SELECT
  SYSDATE,                              -- 2026-05-14 13:00:00
  ADD_MONTHS(SYSDATE, 3),               -- 2026-08-14
  MONTHS_BETWEEN(DATE '2026-12-31', SYSDATE),
  TRUNC(SYSDATE, 'MM'),                 -- 2026-05-01
  EXTRACT(YEAR FROM SYSDATE)            -- 2026
FROM dual;
```

### 날짜 연산

| 연산 | 결과 |
|---|---|
| `DATE + 숫자` | DATE (N일 후) |
| `DATE - 숫자` | DATE |
| `DATE - DATE` | **숫자 (일 차이)** |
| `DATE + DATE` | ✗ (에러) |

## 변환 함수

| 함수 | 동작 |
|---|---|
| `TO_CHAR(n/d, fmt)` | 숫자/날짜 → 문자 |
| `TO_NUMBER(s)` | 문자 → 숫자 |
| `TO_DATE(s, fmt)` | 문자 → 날짜 |

```sql
TO_CHAR(SYSDATE, 'YYYY-MM-DD')        -- '2026-05-14'
TO_CHAR(1234567, '999,999,999')        -- '  1,234,567'
TO_NUMBER('1,234', '9,999')            -- 1234
TO_DATE('2026-05-14', 'YYYY-MM-DD')    -- DATE 값
```

날짜 포맷 코드:

| 코드 | 의미 | 예 |
|---|---|---|
| `YYYY` | 4자리 연도 | 2026 |
| `MM` | 월 (01~12) | 05 |
| `DD` | 일 (01~31) | 14 |
| `HH24` | 24시간 시간 | 13 |
| `MI` | 분 | 30 |
| `SS` | 초 | 45 |
| `D` | 요일 (1=일, 7=토) | 4 |
| `DAY` | 요일명 | '수요일' |

## 묵시적 형변환 함정

> ⚠️ **시험 빈출**

```sql
-- empno가 NUMBER 컬럼일 때
WHERE empno = '7369'    -- '7369' → 7369로 묵시적 변환 (인덱스 무력화 위험)

-- 권장: 명시적 변환
WHERE empno = TO_NUMBER('7369')
-- 또는 애초에 같은 타입으로
WHERE empno = 7369
```

## 시험 빈출 포인트

> 📌 **자주 출제**
> - `SUBSTR`은 1-based
> - `LPAD/RPAD`의 길이 = 결과 **전체** 길이
> - `CEIL(-3.2) = -3`, `FLOOR(-3.2) = -4`
> - `DATE - DATE`는 숫자(일)
> - `MOD(a, b)` 나머지
> - 묵시적 형변환은 인덱스 무력화 위험
> - `NULL`에 함수 적용 → 보통 NULL 반환
