## 1. 정의

**정규화(Normalization)**는 데이터 중복을 제거하고 **이상 현상(Anomaly)**을 방지하기 위해 함수 종속성을 기준으로 테이블을 분해하는 과정이다.

> 💡 **목표**: 데이터 무결성 + 갱신 용이성  
> 💡 **부작용**: 조인 증가로 조회 성능 ↓ (보완: 반정규화)

## 2. 이상 현상 (Anomaly) — 3종 ⭐⭐⭐

비정규화된 테이블에서 발생하는 문제.

### 비정규화 예시

| 학번 | 과목 | 점수 | 학과 | 학과장 |
|---|---|---|---|---|
| 1 | DB | 90 | 컴공 | 김교수 |
| 1 | 알고 | 85 | 컴공 | 김교수 |
| 2 | DB | 80 | 전자 | 이교수 |
| 2 | 회로 | 75 | 전자 | 이교수 |

### 3대 이상 현상

| 이상 | 정의 | 위 예시에서 |
|---|---|---|
| **삽입 이상 (Insertion)** | 원치 않는 정보까지 함께 삽입해야 함 | 학생 없는 새 학과 추가 불가 |
| **갱신 이상 (Update)** | 일부만 갱신되어 데이터 불일치 | 컴공 학과장 변경 시 모든 행 갱신 필요 |
| **삭제 이상 (Deletion)** | 삭제 시 필요 정보까지 함께 사라짐 | 학번 2 학생 모두 삭제 → 전자과 정보 소실 |

> 🔑 **암기법: "삽갱삭"** (삽입·갱신·삭제)

## 3. 함수 종속성 (Functional Dependency) ⭐⭐⭐

`X → Y`: X 값이 결정되면 Y 값이 **유일하게** 결정.

### 종속의 종류

| 종속 | 정의 | 위반 시 |
|---|---|---|
| **완전 함수 종속** | 복합키 **전체**에 종속 | OK |
| **부분 함수 종속** | 복합키의 **일부**에만 종속 | **2NF 위반** |
| **이행 함수 종속** | A → B → C (B를 거쳐 종속) | **3NF 위반** |
| **결정자가 후보키 아님** | 결정자가 후보키 미포함 | **BCNF 위반** |
| **다치 종속 (MVD)** | 다중 값 의존 | **4NF 위반** |
| **조인 종속 (JD)** | 분해 시 정보 손실 가능 | **5NF 위반** |

## 4. 정규형 단계별 ⭐⭐⭐ (가장 중요)

### 🔑 **암기법: "도부이결다조"**

```
1NF → 도메인 (원자값)
2NF → 부분 종속 제거
3NF → 이행 종속 제거
BCNF → 결정자가 후보키
4NF → 다치 종속 제거
5NF → 조인 종속 제거
```

### 4-1. 1NF (제1정규형) — 원자값

> 모든 속성이 원자값(분해 불가)을 가져야 한다.

**위반 사례**:
- 한 컬럼에 콤마로 여러 값 (`'서울, 부산'`)
- 반복 그룹 컬럼 (`전화1, 전화2, 전화3`)
- 배열·JSON

```sql
-- ✗ 1NF 위반
CREATE TABLE 학생 (
  학번 INT,
  취미 VARCHAR(100)   -- '게임, 영화, 독서'
);

-- ✓ 1NF
CREATE TABLE 학생 (학번 INT PRIMARY KEY);
CREATE TABLE 학생_취미 (
  학번 INT,
  취미 VARCHAR(50),
  PRIMARY KEY (학번, 취미)
);
```

### 4-2. 2NF (제2정규형) — 부분 종속 제거

> 1NF + **모든 비주요 속성이 PK 전체에 완전 함수 종속**

복합키의 일부에만 종속되는 속성이 있으면 위반.

> 💡 **단일 PK이면 2NF 자동 만족** (부분 종속이 불가능하므로)

**위반 사례**:
```
주문상세(주문번호, 상품번호, 수량, 상품명, 단가)
PK: (주문번호, 상품번호)

함수 종속:
  (주문번호, 상품번호) → 수량      ✓ 완전 종속
  상품번호 → 상품명, 단가          ← 부분 종속! ✗
```

**해결 (분해)**:
```
주문상세(주문번호, 상품번호, 수량)        ← 완전 종속만 남김
상품(상품번호, 상품명, 단가)              ← 부분 종속 분리
```

### 4-3. 3NF (제3정규형) — 이행 종속 제거

> 2NF + **모든 비주요 속성이 PK에 비이행적으로 종속**

`A → B → C` 처럼 PK가 아닌 속성을 거쳐 종속되면 위반.

**위반 사례**:
```
사원(사번, 이름, 부서번호, 부서명)
함수 종속:
  사번 → 부서번호   ✓
  부서번호 → 부서명  ← 이행 종속! 사번 → 부서번호 → 부서명
```

**해결**:
```
사원(사번, 이름, 부서번호 FK)
부서(부서번호, 부서명)
```

### 4-4. BCNF (Boyce-Codd Normal Form) — 결정자가 후보키

> 3NF + **모든 결정자(Determinant)가 후보키**

3NF는 만족하지만 BCNF는 위반하는 사례 있음.

**위반 사례** (대표 예):
```
수강(학생, 과목, 강사)
PK: (학생, 과목)
함수 종속:
  (학생, 과목) → 강사  ← PK 종속 OK
  강사 → 과목          ← 강사가 결정자이지만 후보키 X → BCNF 위반!
```

**해결**:
```
수강(학생, 강사)
강사_과목(강사, 과목)
```

### 4-5. 4NF — 다치 종속 제거

> BCNF + 다중값 종속(MVD) 제거

한 PK에 대해 두 개의 독립적인 다중 속성이 존재하면 위반.

**위반 사례**:
```
사원(사번, 자격증, 외국어)
한 사원이 여러 자격증 + 여러 외국어 보유 (독립적)
→ 자격증과 외국어를 분리해야 함
```

**해결**:
```
사원_자격증(사번, 자격증)
사원_외국어(사번, 외국어)
```

### 4-6. 5NF — 조인 종속 제거

> 4NF + 조인 종속(JD) 제거

분해된 테이블을 다시 조인했을 때 원본과 정확히 같아야 함. 실무에서는 거의 도달하지 않음.

## 5. 정규형 누적성

| 단계 | 만족 시 |
|---|---|
| 1NF | 원자값 |
| 2NF | 1NF + 부분 종속 X |
| 3NF | 2NF + 이행 종속 X |
| BCNF | 3NF + 결정자=후보키 |

> 💡 BCNF면 1NF·2NF·3NF 자동 만족.

## 6. 반정규화 (Denormalization)

> 정규화가 항상 옳지는 않다.

성능 향상을 위해 의도적으로 중복 허용.

### 반정규화 기법

| 기법 | 설명 |
|---|---|
| **테이블 병합** | 자주 조인되는 테이블 결합 |
| **테이블 분할 (수직)** | 자주 사용 vs 가끔 사용 컬럼 분리 |
| **테이블 분할 (수평)** | 행 단위 분할 (파티셔닝) |
| **중복 컬럼 추가** | 조인 회피용 |
| **파생 컬럼 저장** | 계산 결과 미리 저장 |
| **요약 테이블** | 집계 결과 별도 테이블 |

### 반정규화 시 고려사항

- 데이터 **정합성 관리 부담** 증가
- 갱신 빈도가 높으면 오히려 성능 ↓
- **정규화 후 측정**한 뒤 적용 (선 정규화, 후 반정규화)

## 7. ⚠️ 자주 틀리는 함정

1. **\"단일 PK도 2NF 위반 가능\"** → ✗ 단일 PK는 부분 종속 불가
2. **\"BCNF는 3NF의 약한 형태\"** → ✗ BCNF가 3NF의 강한 형태
3. **\"정규화하면 항상 성능이 좋아진다\"** → ✗ 조인 ↑로 조회 성능 ↓
4. **\"반정규화 = 정규화의 역\"** → △ 의도적 중복 허용
5. **\"이행 종속이 2NF 위반\"** → ✗ 3NF 위반
6. **\"BCNF에서는 다치 종속도 제거된다\"** → ✗ 다치 종속은 4NF
7. **\"3NF면 BCNF\"** → ✗ 결정자가 후보키 아닌 사례 존재

## 8. 📝 기출 출제 패턴

### 패턴 A: 위반 정규형 판별 ⭐ 최빈출
> \"다음 테이블이 위반하는 정규형은?\"
- 함수 종속을 보고 부분/이행/결정자 판별

### 패턴 B: 이상 현상
> \"다음 중 정규화로 해결하는 이상이 아닌 것은?\"
- 삽입/갱신/삭제는 정답, \"조회 이상\" 같은 가짜 답

### 패턴 C: 반정규화 시점
> \"반정규화를 적용해야 하는 경우는?\"
- 빈번한 조인 회피, 조회 성능 우선

### 패턴 D: 정규형 정의
> \"BCNF에 대한 설명으로 옳은 것은?\"
- 결정자 ≠ 후보키 → BCNF 위반

## 9. 🔑 암기법 종합

| 항목 | 암기법 |
|---|---|
| **정규형 6단계** | **도부이결다조** (도메인·부분·이행·결정자·다치·조인) |
| **이상 현상 3종** | **삽갱삭** (삽입·갱신·삭제) |
| **2NF 핵심** | "부분 종속 제거" — 복합키일 때만 발생 |
| **3NF 핵심** | "이행 종속 제거" — A→B→C |
| **BCNF 핵심** | "결정자 = 후보키" |

## 10. 📌 시험 합격 핵심 요약

> **시험장 입실 5분 전 점검**

✅ **6단계 = 도부이결다조** (1NF/2NF/3NF/BCNF/4NF/5NF)

✅ **이상 3종 = 삽갱삭** (삽입·갱신·삭제)

✅ **위반 판별표**:
   - 한 칸에 여러 값 → **1NF 위반**
   - 복합키 일부에 종속 → **2NF 위반**
   - PK 거치지 않고 종속 → **3NF 위반**
   - 결정자가 후보키 아님 → **BCNF 위반**

✅ **단일 PK이면 2NF 자동 만족**

✅ **누적성**: BCNF면 1~3NF 자동 만족

✅ **반정규화**: 정규화 후 필요 시 적용 (성능 ↑ vs 정합성 부담)

✅ **빈출**: \"부분 종속이 어느 정규형 위반?\" → **2NF**

✅ **빈출**: \"이행 종속이 어느 정규형 위반?\" → **3NF**
