## 정의

**식별자(Identifier)**는 엔터티 인스턴스를 유일하게 구분할 수 있는 속성 또는 속성 집합이다.

## 분류 기준

| 분류 기준 | 종류 |
|---|---|
| **대표성** | 주식별자(Primary) / 보조식별자(Alternate) |
| **자생 여부** | 내부식별자 / 외부식별자(FK) |
| **속성 수** | 단일식별자 / 복합식별자 |
| **대체 여부** | 본질식별자(Natural) / 인조식별자(Surrogate) |

## 주식별자의 4가지 특성

1. **유일성**: 인스턴스를 유일하게 식별
2. **최소성**: 유일성을 보장하는 **최소** 속성 수
3. **불변성**: 한 번 부여되면 **변하지 않음**
4. **존재성**: 반드시 값이 존재 (**NULL 불허용**)

## 본질식별자 vs 인조식별자

| | 본질식별자 (Natural) | 인조식별자 (Surrogate) |
|---|---|---|
| 출처 | 업무에서 자연적으로 존재 | 인위적으로 부여 |
| 의미 | 업무적 의미 있음 | 의미 없음 |
| 예 | 주민등록번호, 사업자번호 | 시퀀스 번호, UUID |
| 장점 | 직관적, 의미 있음 | 변하지 않음, 단순 |
| 단점 | 변경 가능성, 복잡할 수 있음 | 인덱스 추가 필요 |

**인조식별자 도입 기준**: 본질식별자가 자주 변하거나, 길거나, 복합키로 너무 복잡할 때.

## FK와 NULL

> 외래키(FK)는 **NULL을 허용할 수 있다**.

관계의 선택성이 "선택"인 경우 FK는 NULL을 허용한다. (예: 부서 미배정 사원의 부서ID)
